# Moodline – Emotion Detection

Moodline is an **NLP & Deep Learning-based Emotion Detection** application that detects emotions from text using a **Bidirectional GRU (BiGRU)** model.

### 🚀 Features

* NLP-based emotion detection
* BiGRU Deep Learning model
* FastAPI backend
* Interactive web interface
* Real-time emotion prediction

### 🛠️ Tech Stack

**Python | NLP | TensorFlow/Keras | BiGRU | FastAPI | HTML | CSS | JavaScript**
